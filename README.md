# Docs That Write Themselves

AI powered documentation generator that writes changelogs, docstrings and PR descriptions from code diffs.

## What It Does
- Reads code diffs
- Generates changelog entries
- Writes function docstrings
- Creates PR descriptions with checklists
- Saves all docs to JSON report

## Tech Stack
- Python 3
- Claude API (Anthropic)
